# Title

## Exploration of Prompting Techniques for AI Video Generation

### Tool Used
**PixVerse AI Video Generator**

### Topic of Video
**A sports car racing on a high-speed track**

---

# Aim

The aim of this experiment is to study how different prompting techniques affect the quality of an AI-generated racing video.

The experiment focuses on:
- Car appearance
- Racing movement
- Track environment
- Lighting
- Camera movement
- Speed
- Visual consistency

Different prompts are created in PixVerse and their outputs are compared.

---

# Tool Used – PixVerse

PixVerse is an AI video generation platform that creates short videos from text prompts.

### Features Used

| Feature | Details |
|---|---|
| Tool | PixVerse |
| Generation Method | Text-to-Video |
| Video Duration | Approximately 5 seconds |
| Visual Style | Cinematic / Realistic |
| Motion | Medium to High |
| Main Task | Sports Car Racing |
| Prompt Type | Text Prompt + Negative Prompt |

---

# Subject Selected

The selected video is:

> **A high-performance sports car racing around a professional racing circuit.**

The video contains:

- Sports car
- Racing track
- Sharp curves
- High-speed movement
- Motion blur
- Track barriers
- Grandstands
- Dynamic camera movement
- Dramatic lighting

---

# Basic Elements of a Video Prompt

| Element | Example |
|---|---|
| Vehicle | High-performance sports car |
| Action | Accelerating and cornering |
| Environment | Professional racing circuit |
| Speed | High-speed racing |
| Lighting | Sunset lighting |
| Camera | Low-angle tracking shot |
| Effects | Motion blur and tire smoke |
| Negative Prompt | Blurry, distorted car, extra wheels |

---

# Prompting Techniques

Four different prompts were tested.

The prompts were gradually improved by adding more information about the car, movement, environment, lighting and camera.
